00音理音理！· Android 音频播放器

多源在线， 本地优先， 原生 Android。

NeriPlayer（音理音理！）把网易云音乐、哔哩哔哩、YouTube Music 与本地音频装进同一个播放器，再配上逐字歌词、GLSL 流体背景、USB 独占与只属于你自己的同步。

基于 Jetpack Compose + Media3，支持 Android 9 及以上。免费开源，GPL-3.0。

01正在播放 · Now Playing

每一首歌，都有自己的颜色。

下面这台手机按 App 源码重绘，并逐项对照真机截图：布局、尺寸、配色和按钮反馈都一致。示例曲《星轨》来自 NeriPlayer PV，按下播放键，它就真的会唱。

Media3 / RuntimeShader

01封面取色，生成流体背景

播放页背景由 BgEffectPainter 加载 GLSL / AGSL 着色器，经 RuntimeShader 逐帧渲染：先用 Palette 从封面提取 Base、Accent、Light、Dark、Bridge 五种色彩角色，再把它们揉成流动的色块与颗粒，并接入 uMusicLevel / uBeat 随节拍律动——不是把封面简单地高斯模糊。

02进度条和主控，放在顺手的地方

播放时进度条变成一条缓缓流动的波形，暂停后回落成直线；等待缓冲时则换成跳动的脉冲。下方按设置显示音质、编码与规格，例如这首 FLAC 的 RAW · 48 kHz，拖动时还会按歌词时间轴给出触感反馈。

正在播放主控位置

单手握持时，把随机、上一首、播放、下一首和循环挪到拇指够得着的底部，进度条也可以一起下来。主控置底时 Dock 会暂时换成普通工具栏，避免两者重叠。

  1. 01波长约 30 dp、振幅约 2.3 dp，每两秒走完一个周期
  2. 02音质标签可点开切换，倍速不为 1.00× 时会单独标出
  3. 03播放页与歌词页的控件还能分别选小 / 中 / 大三档尺寸

SyncedLyricsView

03封面页也有逐字歌词

控制区下方嵌着一段同步歌词：当前行逐字点亮，翻译只跟在当前行下面，其余行安静地淡在一旁。点一行就跳到那里，长按可以分享；嫌挤的话，封面页歌词和底部工具栏都能单独关掉。

  1. 01封面页 18 sp、翻译 14 sp，可与歌词页分别调整字号
  2. 02向左一滑，就进入完整歌词页

PlaybackEffectsController

04音效与倍速

点右上角「更多」，再选「音效与倍速」：速度与音调分开调节，响度增强按 dB 步进，均衡器绑定当前播放会话，内置 23 种系统预设，也能逐个拖动 60 Hz 到 14 kHz 的手动频段。播放设置里还有按歌曲实时分析的响度均衡、声道平衡、32-bit 高解析输出、淡入淡出与交叉淡入淡出。

02歌词 · Lyrics

原文与译文，一同亮起。

完整歌词页把歌词交给整块屏幕：当前行加粗点亮，译文贴在原文正下方，远处的行被景深慢慢模糊。左下角的「译」可以把译文收起或放出。

LRC / YRC / TTML

02仿 Apple Music 的深度歌词

支持逐行与逐字 LRC（含行尾时间与方括号逐字时间戳）、YRC 与 TTML。歌词页只显示当前歌曲真正可用的选项，切歌后等歌词判定完成再渐入，不会先闪一下空白。

  1. 01点击某一行直接跳转；长按选择歌词，复制文本、分享歌曲或生成 1080px 歌词卡片
  2. 02歌词偏移可按来源分别设置默认值；字号在封面页与歌词页分开调
  3. 03来源偏好：自动 / 网易云 / 酷狗 / QQ 音乐 / LRCLIB / AMLL TTML，手动匹配时优先逐字
  4. 04悬浮歌词、状态栏歌词、SuperLyric、词幕 Lyricon 与蓝牙歌词，复用同一条播放数据

04音质 · Hi-Fi

每一个采样，原样抵达。

USB 独占由 native 驱动接管兼容的 USB 音频设备，系统音与其他应用不再共用通道；开启比特完美音量后，软件增益固定为 0 dB，把音量交还给 DAC。

  1. 01UAC1.0 · UAC2.0 Type I PCM设备选择、采样率 / 位深 / 缓冲策略与兼容性开关
  2. 02跟随源采样率先按 USB 描述符尝试源采样率，不可用时回退设备兼容采样率
  3. 0332-bit PCMPCM float 软件转换为设备格式
  4. 04显式反馈时钟解析 UAC2 时钟拓扑与反馈端点，长调度间隙后重新捕获
  5. 05卡死自动恢复启动看门狗、健康审计、原地重配置、动态传输扩缩容，必要时回退系统播放
  6. 06前后台无缝按网络或本地来源选择唤醒策略，回到前台后恢复 USB 独占
  7. 07普通输出也讲究32-bit 高解析输出、实时响度均衡、声道平衡、蓝牙断连暂停
  8. 08边界写清楚隐式反馈或无法验证的拓扑会拒绝 Native 候选，走兼容回退

05一起听 · Listen Together

隔着很远，听同一首歌。

创建房间、分享邀请，所有人的播放进度通过 WebSocket 实时对齐。服务端基于 Cloudflare Workers 与 Durable Objects，你可以一键部署属于自己的那一台。

  1. 01房主 · 听众成员控制开关与控制请求，房主离线检测与恢复
  2. 02同一句歌词，同一秒估算服务端时钟偏移、按漂移阈值校正；单曲循环按时长回绕
  3. 03队列协作拖动、添加与删除按房间版本合并，随机模式复用发起端的真实乱序
  4. 04安全邀请首次加入需要邀请密钥，成员密钥不出现在公开房间状态中
  5. 05候选共享可选共享房主解析的播放候选，每首最多 3 条，不写入离线缓存

06本地与离线 · Local

连接断开，歌还在继续。

播放缓存、下载、歌单、历史和设置默认都留在设备上。网络断开时，首页、探索、播放页、歌词、歌单与下载列表都会切进脱机模式，围绕本地文件与缓存继续运行。

06.1

脱机模式

NetworkStatusMonitor 按系统默认网络承载识别脱机；断网时远程图片请求被阻断，优先用缓存封面。

  • 在线探索与首页刷新
  • 本地文件与已下载歌曲
  • 播放缓存与缓存封面
  • 本地歌单、最近播放与统计
06.2

07同步与隐私 · Sync & Privacy

你的数据，只交给你自己。

NeriPlayer 没有中心化服务器。歌单、收藏、最近播放与播放统计这些元数据，只会同步到你自己的 GitHub 仓库（应用内新建时默认私有）或 WebDAV。

  1. 01延迟 5 秒 · 每小时一次本地变更后延迟同步，另有周期同步；由 WorkManager 调度，只在已验证的网络下执行
  2. 02三路合并歌单、收藏、历史、删除记录与播放统计参与合并，撤销后的歌曲不会被旧删除记录再次移除
  3. 03V4 增量格式Protobuf 记录流 + ZSTD 分块，单个对象不超过 2 MiB，没变的块不再上传
  4. 04原子发布GitHub 以 GraphQL beforeOid 条件更新；WebDAV 先传不可变对象，再以强 ETag 写清单
  5. 05本地加密Cookie、YouTube 授权、GitHub Token 与 WebDAV 密码存在 Android Keystore + EncryptedSharedPreferences

四条承诺

  1. 01
    不接广告，也不追踪。

    不接入广告 SDK、第三方统计或崩溃分析 SDK。

  2. 02
    不做公共曲库。

    不提供云端媒体分发，也不把个人数据汇聚到维护者手里。

  3. 03
    凭据不出设备。

    不会上传音频缓存、下载文件、Cookie 或播放 Token。

  4. 04
    保护你的账号。

    不把本地播放历史回写第三方平台，避免触发风控与异常登录。

i常见问题 · FAQ

有什么想问的？

Q.NeriPlayer 收费吗？可以捐赠支持吗？

完全免费，以 GPL-3.0 协议开源。由于项目的特殊性，维护者不接受任何形式的赞助、捐赠或商业资助。如果想支持它，欢迎提交 Issue、PR，或者把它分享给需要的人。

Q.它自带音乐资源吗？

不提供。NeriPlayer 不构建公共云端曲库或媒体分发服务，在线能力依赖你在第三方平台上的账号授权，会员或受限内容仍需遵循原平台规则。请只在你拥有权利、授权或平台规则允许的范围内访问、播放或保存内容。

Q.我的数据会被上传到哪里？

默认哪里都不去：播放缓存、下载、歌单、历史、统计、设置与授权信息都保存在本机。只有你主动开启 GitHub 或 WebDAV 同步时，歌单、收藏、最近播放和播放统计等元数据才会写入你自己控制的远端；音频缓存、下载文件、Cookie 与播放 Token 不会上传给任何人。

Q.为什么不把播放记录同步回网易云等平台？

应用并非没有这个能力。但中心化音乐平台的客户端通常有风控与行为采样，直接上报本地播放历史可能触发异常登录、异常播放甚至账号冻结。出于保护账号安全的考虑，NeriPlayer 暂不向这些平台上传本地播放历史与统计。

Q.支持哪些 Android 版本？

支持 Android 9（API 28）及以上。播放页的 RuntimeShader 流体背景与高级模糊需要 Android 13+，封面模糊需要 Android 12+，低版本会自动降级，不影响播放本身。

Q.歌词的「音译」在哪里？

只有当前歌曲带有音译数据时才会出现。开启后，音译显示在原文正下方、取代译文的位置；没有音译的歌曲（比如中文歌）只会看到「译」。

Q.“一起听”必须自己搭服务器吗？

不一定。你可以使用他人部署的服务，也可以用 Cloudflare Workers 一键部署自己的 NeriPlayer-LTW，然后在设置页填入地址并测试可用性。房间号是 6 位可读字符；本地歌曲不能创建一起听房间。

Q.GitHub / WebDAV 同步是端到端加密的吗？

不是。凭据在本机以 Android Keystore 加密保存，但同步到远端的文件并不做端到端加密，请自行妥善保管仓库与 WebDAV 账户。完整配置导出文件会包含授权信息，只适合自用迁移，不要公开分享。

Q.USB 独占支持我的 DAC 吗？

当前面向 UAC1.0 与兼容 UAC2.0 Type I PCM 的设备。UAC2 异步链路只接受能解析出唯一显式反馈端点与受支持时钟拓扑的设备，其他情况会走兼容回退。如果息屏后播放被系统限制，请按设置页提示放开电池与后台限制。

Q.遇到问题，怎么反馈最有效？

先在设置页连续点击版本号 7 次开启开发者模式，应用会启用文件日志，崩溃日志会单独落盘。然后到 GitHub Issues 附上系统版本、机型、应用版本、复现步骤与关键日志。也可以用 adb 过滤日志：

adb logcat | findstr NeriPlayer   # Windows
adb logcat | grep NeriPlayer      # Linux / macOS

另外，全局代理可能导致部分第三方接口返回异常数据，请合理配置代理规则。
