## 刚才的 Bug

17:22:07 自动切到 **Take 6 Minus 3** 时播放停止，用户看到断线提示。日志记录的是 **HTTP 416（请求的字节范围不可满足）**，服务器资源拦截器将其提前转成 `SubsonicException`，阻止播放器判断正常文件末尾与真正读取越界。

已修复服务器处理路径：将 416 响应交给 Media3 判断；正常读到末尾不再误报短读断线；真正越界保留位置越界信号，错误不携带认证地址或响应正文。此次没有顺带修改原三个平台的执行路径。

**尚未闭环：** 旧日志没有请求偏移和 `Content-Range`，无法确定这首歌收到 416 的具体原因；修复后是否消除该曲目的报错，仍需真机重播确认。
