## 目标

本原型使用多个服务器配置的数据结构，从第一步隔离资源和缓存；综合搜索和完整服务器管理界面在下一阶段补齐。

## 使用流程

1. 安装构建出的 Debug APK。应用包名带 `.debug`，与正式包分开保存数据；不会继承正式包里的平台登录。
2. 打开“资源库 → 我的音乐 → 音乐服务器”。也可从探索或音乐源设置进入。
3. 输入名称、完整基础地址、用户名和密码，点击“连接并添加”。
4. 地址可为 `https://music.example.com/` 或含端口、反代子路径的形式，例如 `https://music.example.com:4533/navidrome/`；不要填 `/app/` 网页路由或 `/rest/` 接口路径。
5. 选择服务器，浏览专辑；点击歌曲调用现有播放器。搜索框可搜索歌曲或歌手。
6. 播放页继续使用现有封面和歌词组件。服务器没有歌词时不会自动往曲库拉取或写入歌词文件；用户仍可使用音理已有的歌词来源选择/手动匹配。

移除配置只删除本机登录信息，不删除服务器歌曲。已有队列条目会保留原引用；重新添加会生成新的配置 ID，原队列不会自动重绑定。原型阶段更换密码需要移除重加，P1 将补保留 ID 的重新认证。

## 代码改动地图

| 层 | 新增 / 小范围修改 | 目的 |
| --- | --- | --- |
| :model | ServerSongRef | 原始 ID 编码、资源引用、缓存键 |
| :platform | subsonic/auth、api、repository | 配置、鉴权、JSON、资源请求、曲库与歌词映射 |
| :app DI | AppContainer、AppPlayerBindings | 仓库注入，共享 HTTP 拦截器 |
| :app UI | MusicServerViewModel、MusicServerScreen；现有三个入口 | 配置和浏览状态、页面流程 |
| :playback | host、URL 解析、媒体缓存、歌词提供器 | 显式服务器来源分支 |
| :local / :sync | 现有 identity 扩展 | 保留服务器完整身份 |
| :download / :listentogether | 现有执行或导出入口 | 拒绝尚未适配的操作 |

没有新增服务器中间层，也没有改 Navidrome 部署、曲库和歌词文件。

## 构建方式

要求项目所需 JDK 17、Android Platform 37.0、NDK 27.0.12077973、CMake 3.22.1，以及仓库固定的 Gradle 版本。SDK 工具的包名是 `platforms;android-37.0`，不是 `platforms;android-37`。初始化 `np-submodule/accompanist-lyrics-core` 和 `np-submodule/accompanist-lyrics-ui`。

```sh
./gradlew :app:assembleDebug --max-workers=1 --no-daemon \
  -Dorg.gradle.jvmargs='-Xmx1536m -XX:MaxMetaspaceSize=768m -Dfile.encoding=UTF-8' \
  -Pkotlin.compiler.execution.strategy=in-process
```

本机工具链放在父目录 `.android-toolchain/`，SDK 路径写入被 git 忽略的 `local.properties`。这些本机文件不进入上游 PR。上面是构建命令，不包含单元测试或设备测试。

## 全量手动验收表

部分基础场景已有上述真机观察；下表整体仍未验收完成，尤其是多服务器、恢复、导出边界和旧平台回归。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 基础连接 | 正确地址和账号添加 | 专辑显示，重开应用配置仍在 |
| 失败连接 | 错密码、错子路径、服务器断线 | 有错误提示，不保存错误配置 |
| 多服务器 | 添加两个配置并切换 | 列表、歌曲、封面来源不混淆 |
| 搜索 | 搜索、加载下一页、快速换关键词 | 结果正确，旧请求不覆盖新结果 |
| 播放 | 搜索和专辑页点歌、切歌、拖动 | 使用既有播放器；实际格式可播 |
| 系统媒体 | 锁屏、通知栏、后台播放 | 标题和封面可用，播放控制正常 |
| 歌词 | 有逐行词、普通词、无词的歌曲 | 正确显示或为空，offset 无反向偏移 |
| 既有歌词操作 | 手动选择或保存歌词 | 用户选择继续优先 |
| 恢复 | 重启后恢复队列和点击历史 | 请求原服务器，没有网易云 ID 误用 |
| 配置移除 | 移除后再点旧队列歌曲 | 来源不可用；不自动播放同名别服歌曲 |
| 回归 | 既有网易云/B站/YouTube 登录与播放 | 行为不受新增来源影响 |
| 导出边界 | 下载、一起听、混合歌单同步 | 不使用错误平台，不含认证 URL，不误删其他条目 |
