## 模块与依赖

| 层 | 接入点 | 职责 |
| --- | --- | --- |
| `:model` | `ServerSongRef`、现有 `SongItem` / `SongUrlResult` | 原始字符串 ID 的可逆引用、当前媒体键和服务器声明的音频信息；媒体修订隔离仍待修复 |
| `:platform` | `subsonic/api`、`auth`、`repository` | 协议请求、账号、曲库映射、浏览/歌词缓存与资源认证 |
| `:database` | 原有 `PlatformPlaylistCacheRoomStore` | 复用已有分页快照存储，不新增服务器专用数据库 |
| `:app` | `AppContainer` / `AppPlayerBindings`、服务器页面与 ViewModel | 注入 HTTP/仓库，管理页面状态，复用本地歌曲操作 |
| `:playback:runtime` | playback host、URL、缓存、歌词、预取与错误处理 | 服务器显式分支，沿用 Media3 和原有播放状态 |
| `:local` / `:sync` | 现有身份、统计与映射辅助函数 | 保存/还原无凭据来源身份，不同步服务器密码 |
| `:download:runtime` / `:listentogether` | 现有执行或导出入口 | 拒绝尚未适配的服务器歌曲操作 |

库模块不反向读取 `AppContainer`；仓库和 HTTP 由宿主注入。既有平台保留自己的客户端和登录，未增加全平台 Provider 迁移，也未部署媒体代理。

纯 JSON 的 SubsonicClient 接收 profile/password 参数；SubsonicResourceInterceptor 则由宿主注入账号提供者，实际仍直接依赖 auth 包的具体 SubsonicAccounts。这一 api → auth 耦合需要按贡献指南的协议包边界继续评审，不能把 host 注入或现有门禁通过等同于所有新增文件都符合窄依赖约束；是否调整凭据接口或文件归属另行处理。

## 相对最初设计的变化

| 最初设想 | 当前落地 | 说明 |
| --- | --- | --- |
| 首版同时包含资源库、探索综合搜索和发现 | 首个 PR 收敛为服务器媒体库；探索只保留独立入口 | 本次拟将综合搜索、发现和排序后置，剩余范围待维护者评审对齐 |
| 原型搜索只返回歌曲 | 媒体库分“专辑 / 单曲”，歌手作为查询词 | 不增设歌手页签；专辑详情为本地即时筛选 |
| 预留统一 connect、能力快照及 Result 契约 | `SubsonicRepository` 直接返回现有模型；`SubsonicException` 保留错误类别/HTTP 状态 | 未引入新的公共 Result 或能力注册框架；能力 TTL/手动刷新仍待办 |
| 后续再补账号编辑与重新认证 | 已支持名称/地址编辑和改密，保留配置 ID 并增加 revision | 浏览请求/快照、歌词与音频元数据受修订号约束；地址变更后的媒体字节和图片缓存隔离待修复；排序、图标、停用 UI 未完成 |
| 复用公共缓存 | 音频/图片沿用原缓存；曲库增加 Room 快照与同请求复用，歌词增加成功结果缓存 | 复用存储与播放设施，不强行合并不同平台的缓存策略 |
| `getSong` 只预留用于恢复 | 播放解析读取服务器声明的音频元数据，短期缓存避免重复请求 | 不等于自动刷新全部目录或跨源补曲 |
| 下一首预取规划后做 | 已加入非计费网络下的有界预取和取消 | 与当前曲目共用播放缓存，不能视为整首离线下载 |
| 来源身份复用现有字段 | 保持 `SongItem` 字段，以 `ServerSongRef` 集中编码/解码 | Long 代理 ID 不替代完整引用；配置不在跨设备间自动重绑定 |

## 关键约束

配置 UUID 与原始歌曲 ID 一起组成身份，同地址的不同账号互相隔离。队列、历史、歌单只保存可恢复引用；`neri-server.invalid` 内部资源地址在 HTTP 拦截器中解析并生成当次认证，返回给调用方的请求仍为无凭据引用。

播放解析、歌词、下载和共享使用显式来源分支，服务器歌曲不能落入网易云的默认 ID 处理。UI 收藏和添加歌单操作的是音理本地数据，服务端写操作后续独立交付。

媒体库先显示快照，再按新鲜度刷新；搜索分页保持上游顺序，各分类独立维护缓存和滚动位置。切服、换词、更新配置或离开页面时，旧响应不覆盖新状态。歌词成功缓存不被空结果或失败覆盖，但歌词并发请求复用仍未接入。

服务器故障在有限传输重试后保留当前歌曲和进度，供用户手动重试。网络恢复自动续播、跨服务器或第三方平台替代音源继续后置。HTTP 416 修复仅处理服务器路径，交由 Media3 区分正常文件末尾与真正越界。
