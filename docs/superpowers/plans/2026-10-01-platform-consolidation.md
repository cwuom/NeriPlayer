# 平台与歌词模块收敛实施计划

依据：平台收敛设计与用户明确的继续合并、按历史提交信息提交要求

## 实施任务

1. 保存已验证 22 库状态的文件哈希、工作区 diff 和索引；确认模块源码、资源、声明、测试和依赖无合并冲突
2. 由主代理串行把八个平台库与远程歌词源码/测试并入 modules/platform；歌词剩余实现并入 modules/lyrics，原构建缓存与冗余配置留在工作区外
3. 合并插件和依赖，登记唯一 14 库，删除自身依赖和重复引用，维护 api 类型可见性、consumer rules、Manifest 与 assets；不改源码接口和可见性
4. 独立工具代理维护包所有者、模块依赖和新增平台精确域，先验证 API 反向读仓库、跨平台访问、歌词回依赖与输出污染的负面回归；已有 43 域和全部 CRAP 范围保留
5. 主代理同步 Kotlin 源码定位夹具、CI、IDE 和实际测得 internal 方法选择器；独立文档代理根据实际构建更新双语入口及 14 库职责文档
6. 串行完成 Python、Gradle 聚合质量、APK 与模拟器集成验证，核对两轮移动的文件完整性；独立审查完整最终增量并修正确认的问题
7. 根据历史提交风格生成具体提交标题与正文，精确暂存本轮及其必要前置迁移，排除无关 IDE/格式化/其他功能改动；校验暂存内容后实际提交并检查剩余工作区，不推送

## 审查重点

平台客户端与仓库的单向职责是否仍受检查、源码/测试/资源是否丢失、共享类型 api 可见性是否下降、歌词是否仍无平台回边、JS assets 与词幕/Rhino R8 是否完整、质量范围是否缩水，以及索引是否夹带其他工作。

## 执行状态

七项实施任务中的迁移、门禁、文档、验证与暂存审查均已完成。提交按用户授权执行，保持不推送。

最终 14 库，原 43 域原样保留并扩展至 59 域；完整 Python 150 项、工作区 JVM 7592 项通过，2 项已有可选在线 smoke 跳过；独立质量任务与 `verifyModularization` 成功。Debug、未签名 Release 和 AndroidTest APK 构建成功，API 37 模拟器 85 项集成测试通过。Release 资源、词幕 metadata、R8 与 YouTube assets 已核对，两轮基线文件无丢失。

精确宿主所有权修正增加 5 项真实字节码工具回归，不放宽真实仓库规则；新增 4 项逐词歌词识别和 3 项 YouTube 推荐解析测试补足独立模块覆盖。独立审查未发现确认问题。无关工作区修改和生成缓存排除提交，测试用模拟器已停止；在线服务、第三方词幕实际展示和实体 DAC 未验证。
