# 数据库 / Database

## 中文

`:database` 管理 `NeriUserDataDatabase`、Room 实体、DAO、存储入口和版本升级，保存歌单、历史、统计、播放队列、下载记录与平台缓存。

### 结构

- 源码：`src/main/java/moe/ouom/neriplayer/data/local/database`
- 历史 schema：`schemas`
- 依赖：仅 `:model`，通过 KSP 生成 Room 代码
- 业务映射由 `:local` 维护，平台缓存策略由 `:platform` 维护
- 数据库只在应用主进程打开

### 升级

- schema 变更须同步更新导出文件和历史升级链
- 升级须保留旧记录、冲突数据与下载恢复索引
- 旧下载表在数据保全后才能移除
- 兼容升级不可由重建数据库替代

### 测试

`DatabaseUpgradeInstrumentedTest` 使用真实 Room 检查历史升级和旧下载数据保留，需连接 Android 模拟器运行。

```bash
./gradlew :database:testDebugUnitTest :database:lintDebug
./gradlew :database:connectedDebugAndroidTest
```

## English

`:database` owns `NeriUserDataDatabase`, Room entities, DAOs, stores, and migrations. It persists playlists, history, statistics, the playback queue, download records, and platform caches.

### Layout

- Sources: `src/main/java/moe/ouom/neriplayer/data/local/database`
- Historical schemas: `schemas`
- Dependencies: `:model` only; Room code is generated by KSP
- `:local` owns business mappings and `:platform` owns cache policies
- The database opens only in the app's main process

### Migrations

- Schema changes require updated exports and historical migrations
- Migrations preserve old records, conflicting data, and download recovery indexes
- Legacy download tables can be dropped only after their data is preserved
- A compatible migration cannot be replaced by rebuilding the database

### Tests

`DatabaseUpgradeInstrumentedTest` checks historical upgrades and legacy download preservation against real Room. It requires a connected Android emulator.

```bash
./gradlew :database:testDebugUnitTest :database:lintDebug
./gradlew :database:connectedDebugAndroidTest
```
